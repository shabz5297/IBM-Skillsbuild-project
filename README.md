# A gamified web app for IBM SkillsBuild

## Description
As a group, we are gamifying elements of the IBM SkillsBuild web application to encourage students to use and engage with the platform

## System Architecture

See [System Architecture](Documentation/architecture.md)

## Local Development Setup

1. Install MySQL
2. Create a local database called `group05`
3. Create a MySQL user `group05`
4. Set your password in `application-local.properties`
5. Run the Spring Boot application
6. Access at http://localhost:8080
